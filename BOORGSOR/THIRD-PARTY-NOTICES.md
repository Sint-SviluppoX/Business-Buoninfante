# Componenti di terze parti

## ExcelDataReader 3.6.0

Usato per leggere file Excel `.xls` senza richiedere Microsoft ACE OLEDB.

- progetto: https://github.com/ExcelDataReader/ExcelDataReader
- pacchetto: https://www.nuget.org/packages/ExcelDataReader/3.6.0
- licenza: MIT

Il binario distribuito si trova in `lib/ExcelDataReader.dll` ed è stato estratto
dal pacchetto NuGet ufficiale `ExcelDataReader` versione 3.6.0.
